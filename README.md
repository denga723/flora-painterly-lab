# Flora / Painterly

An interactive study of painterly rendering in Blender: one scene, eight treatments, three palettes, and four lighting setups.

- Drag directly over images to compare a treatment with the original.
- Switch palettes and lighting from the main gallery.
- Watch synchronized lighting comparisons and inspect individual Kuwahara controls.

## Contents

110 rendered PNGs, 27 MP4 videos, comparison sheets, and the treatment settings. The gallery is static HTML, CSS, and JavaScript and runs on GitHub Pages without a build step.

## Credits

Vegetation and rock models: [Flora Paint by Casey Sheep](https://caseysheep.gumroad.com/l/flora-paint-stylized-tree-and-plants-library). Rendering: Blender 5.2.2 EEVEE. Classic and Anisotropic are native Kuwahara modes; Gouache, Watercolor, and Colored pencil are custom compositor recipes.

This repository includes rendered artwork, not the purchased source asset library or Blender project files.
